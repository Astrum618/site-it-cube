Программирование на Python

Освоение Python от основ до веб-разработки: алгоритмы, ООП, базы данных, API и собственные IT-проекты — за 3 года обучения.

Возраст: 12–17 лет
Длительность: 432 академических часов
Группы: 10–14 человек

Python — один из самых популярных и востребованных языков программирования в мире. Его синтаксис прост и интуитивно понятен новичкам, поэтому он идеально подходит для первого знакомства с IT. Python используется в веб-разработке, анализе данных, машинном обучении и автоматизации.

Программа «Программирование на Python» построена по принципу «от простого к сложному» и состоит из трех модулей: стартового, базового и продвинутого. Ребята не просто изучают синтаксис, а учатся решать реальные прикладные задачи и создавать собственные IT-продукты.

Чему научится ребёнок?

1

Умение писать и отлаживать код на Python для решения различных задач.

2

Знание основ применения языка в различных областях IT.

3

Умение писать эффективный и оптимизированный код.

4

Навык создания MVP (минимально жизнеспособных) проектов.

5

Разработка эффективных алгоритмов и работа со сложными структурами данных.

Программа обучения

Для новичков 12–16 лет. Свободный набор без предварительного отбора.

  • Раздел 1. Введение в программирование: инструктаж, среда разработки, переменные, типы данных, условные конструкции, строки.
  • Раздел 2. Базовые конструкции в Python: циклы for и while, работа со списками.
  • Раздел 3. Функциональное программирование: словари, множества, двумерные массивы, функции и рекурсия, работа с файлами, основы ООП.
  • Раздел 4. Проектная деятельность: гибкое управление проектами, разработка MVP, эффективная презентация, итоговая защита проекта.

Для тех, кто уже имеет первичные навыки (13–17 лет). Зачисление после стартового уровня или тестирования.

  • Раздел 1. Программирование на Python: углублённое ООП, рекурсия, *args/**kwargs, модуль OS, исключения, пакеты и модули.
  • Раздел 2. Функциональное программирование: lambda-функции, функторы, декораторы, регулярные выражения.
  • Раздел 3. Графическая библиотека Tkinter: создание GUI, виджеты (Listbox, Entry, Canvas), многооконные приложения, калькулятор, ежедневник, фотоальбом.
  • Раздел 4. Проектная деятельность: управление проектами, разработка, презентация, защита.

Для уверенных пользователей (14–17 лет). Зачисление после базового уровня или углублённого тестирования.

  • Раздел 1. SQL: методы хранения информации, CSV, системы контроля версий, SQL-запросы (SELECT, INSERT, UPDATE, DELETE), мини-проект с БД.
  • Раздел 2. WEB: как работает браузер, библиотека requests, JSON, API, веб-сервер Flask, шаблонизаторы, ORM, FastAPI, контейнеризация (Docker), деплой.
  • Раздел 3. Проектная деятельность: разработка под потребности заказчика (user stories, ТЗ, Agile/Scrum/Waterfall), процесс разработки, презентация, итоговая защита.
